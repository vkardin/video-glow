# Video Glow

Ambient glow around any HTML5 video on any site, also in fullscreen (fills the black bars on 16:10 screens). Shape, blur, edge softness, pause behaviour, fullscreen and per-site settings are adjustable. Languages: English, Русский, Українська.

- Extension source: [`extension/`](extension) — load it via `chrome://extensions` → Developer mode → Load unpacked.
- Website: https://vkardin.github.io/video-glow/ (GitHub Pages from [`docs/`](docs)), privacy policy: [`docs/privacy.html`](docs/privacy.html).
- Store listing texts, test scripts and graphics: [`store/`](store).

Video Glow collects no data and makes no network requests.
